My Friends – PWA version

A fully working Progressive Web App of the My Friends spec. Built with plain HTML/CSS/JavaScript — no Mac, no Xcode, no build step, no internet required. Data is stored on-device in the browser's IndexedDB.

Run it on your Windows PC

  1. Open PowerShell in this folder.
  2. Run: 
    powershell -ExecutionPolicy Bypass -File .\serve.ps1
  3. Open http://localhost:8080 in Chrome or Edge.
  4. Set a PIN in ⚙︎ Settings, add a friend, try Search and Reports.

Use a different port if 8080 is busy: .\serve.ps1 -Port 8090

Install on your iPhone (no App Store)

Your PC and iPhone must be on the same Wi-Fi.

  1. Find your PC's IP: run ipconfig and note the IPv4 address (e.g. 192.168.1.20).
  2. Edit serve.ps1 prefix to http://+:8080/ or host the folder somewhere with HTTPS (below).
  3. On the iPhone open Safari → http://YOUR-PC-IP:8080.
  4. Tap Share → Add to Home Screen. The app icon appears; it launches full-screen and works offline.
Best practice for a permanent install: put this folder on free static hosting with HTTPS (GitHub Pages, Netlify Drop, or Cloudflare Pages). iOS enables full offline PWA behaviour reliably over HTTPS. Then just open the URL in Safari and Add to Home Screen — after first load it runs with no network at all.
